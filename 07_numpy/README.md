# 07. 혈액형과 MBTI는 과학인가 미신인가 — 당신의 MBTI는?

> 자체 제작 설문 데이터를 통계·ML로 분석해 MBTI가 성격을 예측하는 도구로 유효한지 검증한 프로젝트

`Python` `Pandas` `NumPy` `Scikit-learn` `Matplotlib` `Seaborn` | 2026.02.27 ~ 03.02 | 팀 프로젝트  
**담당:** 자체 설문 데이터 탐색적 분석 · MBTI 임계값 기반 판정 · 로지스틱 회귀 및 랜덤 포레스트 구현 및 시각화

### 분석 목표 및 가설

데이터: 팀 자체 제작 구글폼 설문 (유효 응답 약 90명 / E·I·S·N·T·F·J·P 지표별 9문항 × 7점 리커트 척도)

- **가설 1** 지표별 설문 평균이 4.0을 기준으로 MBTI 유형을 판별할 수 있을 것이다
- **가설 2** 로지스틱 회귀·랜덤 포레스트로 지표별 예측 정확도를 높일 수 있을 것이다

### 주요 결과

| 지표 | 로지스틱 회귀 | 랜덤 포레스트 |
|------|-------------|-------------|
| E/I | 87.50% | **93.75%** |
| S/N | **81.25%** | 68.75% |
| T/F | 81.25% | 81.25% |
| J/P | **62.50%** | 56.25% |
| 전체 MBTI (16클래스) | 31.25% | 37.50% |

- **가설 1·2 부분 지지** — 지표별 이진 분류는 E/I에서 최대 93.75% 달성했으나, 16개 클래스 전체 예측은 두 모델 모두 40% 미만
- J/P 지표가 두 모델 모두 가장 낮은 정확도 → 해당 설문 문항이 J/P 성향을 명확히 구분하지 못했을 가능성
- MBTI 신뢰도 평균 4.55점(7점 만점), 응답자 다수가 상대방 MBTI를 알아도 태도 변화 없다고 응답 → 실생활 영향력은 제한적

### 트러블슈팅

**로지스틱 회귀 16클래스 분류 수렴 실패**  
기본 `max_iter=100`으로는 다중 클래스 최적해에 수렴하지 못해 경고 발생.  
`max_iter=1000`으로 상향 조정하여 해결.

**'모름/검사 안 해봄' 응답 포함 시 정확도 계산 오류**  
자기보고 MBTI가 없는 응답자는 정확도 비교 대상이 될 수 없음.  
Boolean 마스크(`valid_value`)를 생성해 정확도 계산·모델 학습·시각화 전 단계에 일관되게 적용하여 해결.

**지표별 시그모이드 곡선 시각화 시 단일값 입력 불가**  
9개 피처로 학습된 모델에 평균값 1개만 입력할 수 없는 구조적 한계.  
시각화 전용으로 평균값 1개를 입력으로 하는 단순 로지스틱 회귀 모델을 별도 학습하여 해결 — 분석용 모델과 시각화용 모델을 목적에 따라 분리하는 설계 경험.
