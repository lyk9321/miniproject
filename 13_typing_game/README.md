# 13. 한컴타자연습

> 한컴타자연습을 모티브로 레벨별 난이도 조정·특수 단어 메커니즘·90년대 클래식 UI를 구현한 pygame 타자 게임

`Python` `pygame` | 2026.04.24 ~ 04.27 | 개인 프로젝트

### 주요 기능

- **언어 선택** — 한국어 / 영어 중 선택, 선택 언어 단어만 출제
- **레벨별 난이도** — CSV의 difficulty(1~4) 기준으로 레벨이 오를수록 중급·고급 단어 순차 출제
- **Word Bag 시스템** — 동일 난이도 단어를 한 번씩 고루 출제 후 반복, 과도한 중복 방지
- **특수 단어** — 20~30초 간격으로 빨간 단어가 가로로 이동 등장, 맞히면 화면 전체 초기화 + 보너스 점수
- **레벨 5 이상 깜빡임** — 1초 주기(0.9초 표시 / 0.1초 숨김)로 난이도 추가
- **한글 IME 실시간 조합 표시** — 조합 중인 글자(ㅁ → 메 → 메뉴)를 입력창에 실시간 표시
- **ESC 메뉴 + 일시정지 보정** — 팝업 열린 시간을 누적해 게임 타이머에서 제외

### 트러블슈팅

**한글 조합 중인 글자가 입력창에 표시되지 않는 문제**  
`KEYDOWN` 이벤트만 사용하면 IME가 조합을 완료한 뒤에야 글자를 전달해 중간 상태를 볼 수 없음.  
`TEXTEDITING` 이벤트를 추가 처리해 조합 중 글자를 `composition_text`에 저장하고 확정된 글자와 나란히 표시, `pygame.key.start_text_input()`으로 IME 활성화.

**단어 입력 중 Q·T 키가 기능키로 인식되는 오작동**  
`quit`, `type` 같은 단어 입력 도중 Q·T 키가 메뉴 복귀·리셋 기능을 실행하는 충돌 발생.  
플레이 중에는 알파벳 키를 기능키로 인식하지 않도록 설계 변경, ESC 키 하나만 메뉴 진입 용도로 남기고 모든 기능을 ESC 팝업 안에서만 작동하도록 재설계.

**ESC 메뉴 열린 동안 게임 타이머가 계속 흘러 팝업 닫을 때 단어가 쏟아지는 문제**  
`pygame.time.get_ticks()`를 그대로 사용해 일시정지 개념이 없었음.  
`pause_start_time`과 `total_paused_time`을 추가해 팝업 열릴 때 정지 시각 기록, 닫힐 때 경과 시간 누적. 이후 모든 타이머 계산을 `get_game_time() = pygame.time.get_ticks() - total_paused_time` 기준으로 통일.
