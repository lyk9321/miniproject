# 10. 연기·불꽃 실시간 탐지를 통한 산불 조기 경보 시스템

> YOLOv8 경량화 전후 4개 모델의 탐지 성능을 정량 비교하여 산불 조기 경보 목적에 최적인 배포 모델을 도출한 프로젝트

`Python` `YOLO` `PyTorch` `Pandas` `NumPy` `Matplotlib` `Seaborn` | 2026.03.31 ~ 04.02 | 팀 프로젝트  
**담당:** 모델 결과 분석 및 모델 비교 (베이스라인 케이스 분류 시각화 · 4개 모델 정량 비교 · 변화 케이스 자동 추출)

### 비교 대상 모델

| 모델 | 설명 |
|------|------|
| baseline_pt | YOLOv8 PyTorch 베이스라인 |
| opt_pt | 최적화된 PyTorch 모델 |
| onnx_fp32 | ONNX FP32 변환 모델 |
| onnx_int8 | ONNX INT8 양자화 모델 (2.98MB) |

### 주요 결과

**신뢰도 분포 변화 (Seaborn boxplot)**

| 클래스 | baseline_pt 중앙값 | opt_pt 이후 |
|--------|-----------------|------------|
| smoke | 0.57 | **0.70** (분포 폭도 좁아짐) |
| fire | 0.44 | **0.52~0.53** |

**FP·FN 오류 집계**

| 모델 | FN_smoke | FN_fire |
|------|---------|---------|
| baseline_pt | 299건 | 118건 |
| opt_pt | 120건 (↓60%) | 76건 (↓36%) |
| **onnx_fp32** | **113건** | **69건** ← 최소 |
| onnx_int8 | 131건 | 75건 |

**최종 선정: onnx_fp32** — 산불 조기 탐지 목적(실화재 미탐지 최소화)에서 FN이 가장 적음. 모델 복잡도 증가가 반드시 성능 향상으로 이어지지 않는다는 점을 수치로 확인.

### 트러블슈팅

**4,306장 전체에서 경량화 전후 변화 케이스를 체계적으로 추출하기 어려운 문제**  
`analysis_df`를 이미지 단위로 구축할 때 `success_fire`, `fn_fire` 등 이진 컬럼을 미리 설계하고, baseline과 비교 모델 결과를 이미지 키로 `merge` 후 조건 필터링으로 변화 케이스를 자동 추출하는 로직 작성. 육안 확인 없이 데이터 기반으로 변화 케이스 도출.

**OpenCV BGR → Matplotlib RGB 색상 반전 문제**  
`result.plot()`으로 얻은 추론 이미지를 Matplotlib으로 출력하면 색상이 반전되어 표시됨.  
`cv2.cvtColor(img, cv2.COLOR_BGR2RGB)` 적용으로 채널 순서 변환 후 해결.
