# 03. 2022 FIFA 월드컵 데이터 분석 — 승리 요인 도출

> 2022 카타르 월드컵 데이터를 포지션별로 분석하여 우승팀 아르헨티나의 강점·약점을 수치로 도출한 프로젝트

`Python` `Pandas` `Matplotlib` `Seaborn` | 2026.01.27 ~ 01.28 | 팀 프로젝트  
**담당:** 우승팀 아르헨티나 전략 지표 분석 (데이터 수집 · 전처리 · 시각화 · 결과 해석)

### 분석 목표 및 가설

- **가설 1** 아르헨티나는 전 포지션에서 상위권에 위치할 것이다
- **가설 2** 특정 포지션에서 두드러진 강점이 있으며, 그것이 우승의 핵심 요인으로 작용했을 것이다

### 주요 결과

| 포지션 | 결과 |
|--------|------|
| GK | 실점 흐름에서 변동성 관찰 — 실점 리스크 존재 |
| DF | 태클·블록·인터셉션·클리어링 중위권 — 수비 수치 특출나지 않음 |
| MF | 패스 시도·성공률·전진 패스 **상위권** — 중원 점유와 전진 전개로 경기 주도 |
| FW | 유효슈팅·xG·득점 **상위권** — 기회를 득점으로 연결하는 높은 결정력 |

- **가설 1 부분 기각 / 가설 2 지지**
- 수비 불안정성을 MF의 경기 주도 + FW의 높은 결정력 조합으로 극복한 것이 우승 요인

### 트러블슈팅

**6개 파일 병합 시 선수 이름 표기 불일치로 대량 결측 발생**  
파일마다 선수 이름 표기가 미세하게 달라 `merge()` 시 같은 선수가 다른 행으로 분리됨.  
`player_stats`를 기준으로 `how='left'` 병합 후 `fillna(0)`으로 일괄 처리.

**팀 간 출전 시간 차이로 단순 합산 비교 불공정**  
출전 선수 수와 총 출전 시간이 팀마다 달라 단순 합산 수치로는 비교 불가.  
`groupby().sum()` 후 `minutes_90s`로 나눠 90분당 수치(per90)로 정규화하여 해결.
