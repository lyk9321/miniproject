# 02. 서울특별시 연료별 자동차 등록현황과 대기오염 지표 분석

> 친환경차 보급 확대와 대기질 개선 간의 상관관계를 2018~2024년 실데이터로 검증한 프로젝트

`Python` `Pandas` `Matplotlib` `Seaborn` | 2026.01.14 ~ 01.21 | 팀 프로젝트  
**담당:** 대기오염 지표 데이터 수집 · 전처리 및 정규화 · 분석 · 시각화 · 발표 자료 정리

### 분석 목표 및 가설

- **가설 1** 친환경차(전기·하이브리드·수소) 등록 비율이 증가할수록 대기오염 물질 농도는 감소할 것이다
- **가설 2** 경유차 등록 비율이 감소할수록 이산화질소 농도는 감소할 것이다

### 주요 결과

| 가설 | 상관계수 | 결과 |
|------|---------|------|
| 친환경차 비율 ↑ — 이산화질소 ↓ | r = −0.454 | ✅ 지지 |
| 경유차 비율 ↓ — 이산화질소 ↓ | r = +0.469 | ✅ 지지 |
| 전기차 등록 대수 — 이산화질소 | r = −0.979 | 강한 음의 상관 |
| 하이브리드 등록 대수 — 이산화질소 | r = −0.992 | 강한 음의 상관 |

2018~2024년간 경유차 비율 37% → 30% 감소, 친환경차 비율 2% → 11% 급증과 함께 이산화질소 농도도 뚜렷한 하락세를 보임.

### 트러블슈팅

**두 데이터셋 병합 시 열 이름·타입 불일치**  
대기오염 데이터에 문자 혼입, 자동차 데이터 열 이름에 단위·분류 정보가 섞여 있어 단순 병합 시 오류 발생.  
`rename()`으로 열 이름 정리 → `apply(pd.to_numeric, errors='coerce')`로 타입 통일 → `set_index()`로 시점 기준 맞춘 뒤 `join()`으로 병합하여 해결.

**단위가 다른 두 지표를 하나의 그래프에 표현**  
미세먼지(㎍/㎥)와 이산화질소(ppm)의 스케일 차이로 단일 축 표현 불가.  
`twinx()`로 2축 그래프를 구성하여 해결.
