### 트러블슈팅

**타 회사 공고 혼입 오탐**  
페이지 전체에서 `rec_idx=` 링크를 추출하면 추천 공고가 대거 혼입됨.  
`#recruit_info_list` 컨테이너 안으로 추출 범위를 제한하고, `corp_name` 요소에서 회사명 일치 여부를 추가 검증하는 이중 필터링 로직으로 해결.

**섹션 라벨 단어가 형태소 분석 상위에 올라오는 문제**  
'담당업무', '자격요건' 등 라벨이 실제 역량 키워드를 덮음.  
`SECTION_STOPWORDS` 불용어 사전을 직접 작성(25개)하고 2글자 미만 토큰도 추가 필터링해 의미 있는 키워드만 상위에 노출되도록 개선.

**복합 고용형태 집계 왜곡 ('정규직/계약직' 혼기재)**  
단순 첫 값 추출 방식으로는 비율이 왜곡됨.  
복합 고용형태를 1/n 가중치로 분할 집계하는 방식으로 전체 공고 수 기준 비율이 정확하게 유지되도록 처리.
