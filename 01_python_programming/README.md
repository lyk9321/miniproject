# 01. Python Programming

## 01-1. Travel Archive
> 여행 사진을 키보드·버튼으로 탐색할 수 있는 tkinter 기반 포토 갤러리 프로그램

`Python` `tkinter` | 2026.01.07 ~ 01.11 | 개인 프로젝트

### 주요 기능
- PNG 이미지 30장을 갤러리 형식으로 출력
- 버튼 클릭 및 방향키로 이전/다음/처음/마지막 페이지 이동
- 이미지 파일명과 장소 설명 텍스트를 함께 표시

### 트러블슈팅
**처음·마지막 페이지 이동 후 다음 버튼 오작동**  
`goStart()` / `goEnd()` 함수 내 `num` 변수 초기화 누락이 원인.  
각 함수에 `global num` 선언 및 값 초기화 추가로 해결.

## 01-2. 축구 선수 이름 맞히기
> 선수 사진 DB에서 무작위로 10문제를 출제하고 정답을 판별하는 tkinter 기반 GUI 퀴즈 프로그램

`Python` `tkinter` | 2026.01.11 ~ 01.12 | 개인 프로젝트

### 주요 기능
- 선수 이미지 50장 DB에서 `random.sample()`로 매 게임 다른 10문제 출제
- 엔터키·제출 버튼 두 가지 방식으로 답안 입력
- 정답/오답 실시간 카운트 및 10문제 종료 후 점수별 결과 메시지 팝업 출력

### 트러블슈팅
**무작위 추출된 이미지와 정답 데이터 매핑 문제**  
이미지 파일명(`1.png` ~ `50.png`)에서 숫자만 추출하여 정답 리스트의 인덱스로 활용하는 방식으로 이미지–정답 연결 구조를 해결함.
