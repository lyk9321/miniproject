# 12. KBO 원정 경기 플래너

> 응원팀 입력 시 AI 승률 예측·날씨 리스크·맛집·숙소까지 한 번에 제공하는 KBO 원정 팬 올인원 플래너

`Python` `Selenium` `BeautifulSoup` `Scikit-learn` `Streamlit` `Pandas` `NumPy` | 2026.04.17 ~ 04.20 | 팀 프로젝트  
**담당:** KBO 데이터 크롤링 · 기상청 API 연동 · 로지스틱 회귀 모델 학습 · 추천도 공식 설계 · Streamlit 대시보드 구현

### 파일 구조

```
crawl_kbo.py         : KBO 공식 홈페이지 2016~2025 시즌 크롤링 (약 7,200경기)
crawl_kbo_2026.py    : 2026 시즌 추가 수집 + 기존 데이터 병합
feature_calculator.py: 최근폼·상대전·원정승률 점수 계산 (콜드 스타트 처리 포함)
model_trainer.py     : 로지스틱 회귀 모델 학습 → kbo_model.pkl 저장
weather_api.py       : 기상청 단기예보 API 연동 (9개 구장 격자 좌표 매핑)
score_calculator.py  : 4개 지표 가중 합산 → 최종 추천도 계산
tab1.py              : Streamlit 대시보드 구현
```

### 추천도 공식 설계

| 지표 | 가중치 | 계산 방법 |
|------|--------|---------|
| 승률 예측 | 35% | 로지스틱 회귀 모델 (원정팀 승리 확률) |
| 최근 폼 | 25% | 이번 시즌 최근 10경기 승률 |
| 상대 전적 | 20% | 이번 시즌 + 최근 3시즌 맞대결 승률 |
| 원정 승률 | 20% | 이번 시즌 전체 원정 경기 승률 |
| 날씨 | 미포함 | 우천 확률 71% 이상 시 '재검토 권장' 별도 출력 |

추천 등급: 70점 이상 → 추천 / 50~69점 → 보통 / 50점 미만 → 비추천

### 모델 성능

로지스틱 회귀 (학습: 2016~2025 / 테스트: 2026 시즌 87경기)

- 테스트 정확도: **60.9%** — 변수가 많은 야구 종목에서 통계 기반 모델로 유의미한 수준
- 원정팀 시즌 승률(계수 +0.1321)이 예측에 가장 큰 영향
- 홈팀 승 예측 recall(0.79) > 원정팀 승 예측 recall(0.43) → 모델이 홈 어드밴티지를 학습

### 트러블슈팅

**시즌 초반 콜드 스타트 — 점수가 극단값(0점 또는 100점)으로 치우치는 문제**  
이번 시즌 경기 수가 기준치(최근 폼 10경기 / 상대전 5경기 / 원정 승률 10경기) 미만일 때 발생.  
`이번시즌경기수 / 기준치`를 이번 시즌 가중치로 설정하여 지난 시즌 데이터를 자동 혼합하는 가중 평균 로직 구현. 경기 수가 쌓일수록 지난 시즌 영향이 자연스럽게 감소하는 구조로 설계.

**피처 엔지니어링 시 데이터 누수 가능성**  
전체 데이터를 먼저 합산 후 피처를 계산하면 미래 데이터가 과거 경기 피처에 반영되는 문제.  
피처 계산 시 반드시 `df["날짜"] < before_date` 조건으로 해당 경기 이전 데이터만 필터링. 학습/테스트 분리도 `shuffle=False`로 시간 순서를 유지하고 2026 시즌을 테스트셋으로 분리하는 시계열 분할 방식 적용.
