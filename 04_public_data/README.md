# 04. 기후 변화가 사계절을 알리는 지표에 미치는 영향

> 가을철 기온·강수량 변화가 단풍·은행나무 시작 시기에 미치는 영향을 상관분석과 시각화로 탐색한 프로젝트

`Python` `Pandas` `Matplotlib` `Seaborn` | 2026.02.03 ~ 02.04 | 팀 프로젝트  
**담당:** 가을 파트 (지표 데이터 수집 · 전처리 · 분석 · 시각화 · PPT 제작)

### 분석 목표 및 가설

분석 기간: 1989-2019년 (31개 시점) / 가을 구간: 입추~입동 (8/7-11/6)

- **가설 1** 가을 기온이 높을수록 단풍·은행 시작일이 늦어질 것이다 (양의 상관관계)
- **가설 2** 강수량이 많을수록 단풍·은행 시작일이 늦어질 것이다 (양의 상관관계)

### 주요 결과

| 변수 쌍 | 상관계수 | 결과 |
|---------|---------|------|
| 단풍 × 기온 | r = 0.43 | ✅ 부분 지지 — 따뜻한 가을이 단풍을 늦춤 |
| 은행 × 기온 | r = 0.01 | ❌ 기각 — 사실상 상관관계 없음 |
| 단풍 × 강수량 | r = 0.34 | ✅ 지지 |
| 은행 × 강수량 | r = 0.40 | ✅ 지지 — 은행은 기온보다 강수량과 더 뚜렷한 상관 |
| 단풍 × 은행 시작일 | r = 0.56 | 두 지표가 함께 이동 — 기후변화가 가을 생태계 전반에 영향 |

### 트러블슈팅

**날짜 데이터를 시각화용·분석용으로 이중 처리해야 하는 문제**  
단풍·은행 시작일이 날짜 형식으로 저장되어 있어, y축에는 월-일로 표시하면서 상관분석에는 숫자로 사용해야 했음.  
시각화용: 기준연도(2001) 부여한 `Timestamp`로 변환 → `mdates.DateFormatter('%m-%d')`로 월-일 표시.  
분석용: `dt.dayofyear`로 DOY(연중 일수) 숫자 변환을 별도 처리하여 두 형태를 동시에 유지.
